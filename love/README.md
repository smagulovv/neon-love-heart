# Neon Code Heart

Небольшая анимация на чистых HTML, CSS и JavaScript. Canvas постепенно заполняет математическую форму сердца цельными фразами «я люблю тебя» на 47 языках. Размер текста подбирается под ширину каждой строки силуэта, чтобы фразы оставались внутри контура.

## Запуск

Из каталога проекта запустите любой локальный HTTP-сервер. Например, с установленным Python:

```bash
python -m http.server 8000
```

Затем откройте <http://localhost:8000>.

## Управление

Элементы управления проявляются после движения указателя или нажатия клавиши: перезапуск, пауза, скорость формирования, сила свечения и выбор палитры. На сенсорном устройстве коснитесь экрана, чтобы показать настройки. При включённом `prefers-reduced-motion` сердце показывается в спокойном статичном режиме.

Размер Canvas подстраивается под окно, а плотность пикселей ограничена значением 2 для экономии ресурсов.
